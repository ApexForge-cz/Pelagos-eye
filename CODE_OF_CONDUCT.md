# Code of Conduct

OceanScope expects respectful, evidence-focused collaboration. Harassment, discriminatory
language, threats, deliberate exposure of private information, and bad-faith disruption are
not acceptable in issues, discussions, reviews, or other project spaces.

Report conduct or security concerns privately to the repository owner through the private
reporting channel configured on the repository. Until that channel exists, do not publish
sensitive details in a public issue. The maintainer may edit, close, or remove contributions
that violate these expectations and may restrict participation when necessary.

This project is maintained by one person and does not promise a response time. Technical
disagreement is welcome when it remains specific, civil, and grounded in reproducible
evidence.
