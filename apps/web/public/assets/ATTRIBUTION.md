# Globe visual assets

- `land_ocean_ice_2048.png`: NASA Visible Earth, Blue Marble land surface,
  ocean color, sea ice, and clouds; public NASA imagery. Source:
  <https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57730/land_ocean_ice_2048.png>
- `ne_110m_admin_0_countries.geojson`: Natural Earth 1:110m Admin 0 Countries,
  public domain. Source:
  <https://github.com/nvkelso/natural-earth-vector/tree/master/geojson>

These files provide visual context only. They are not navigational charts, coverage
evidence, or sources for OceanScope operational records.
